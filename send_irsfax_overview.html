Overview: send_irsfax.py

This script automates the process of finding IRS-related emails and forwarding their attachments to an online fax provider. It relies on a JSON configuration file to supply IMAP credentials, fax API endpoints, and delivery metadata.

Core Steps

  • Load configuration: Reads fax_config.json, ensuring required keys exist and capturing optional behavior toggles like timeout minutes or headers.
  • Connect to IMAP: Establishes an SSL session (default Gmail) and selects the configured mailbox, toggling read-only mode if mark_read is false.
  • Search for IRSFax: Builds an IMAP UID search targeting the configured subject keyword (default IRSFax) and, if requested, only unseen messages.
  • Download attachments: Fetches the latest matching message, iterates over MIME parts, and writes all attachments to a temporary directory with collision-safe filenames.
  • Send fax: Posts to the fax provider using requests, streaming each saved attachment and merging in configured form fields, headers, and the API key.
  • Clean up: Logs success, optionally marks the email as seen, and logs out in a finally block to ensure proper IMAP teardown.

Configuration Highlights

  • Core keys: email_user, email_password, fax_api_url, fax_api_key, and fax_to must be set.
  • Optional customization: fax_fields (extra form fields), fax_headers, fax_attachment_param, and request_timeout_minutes.
  • Behavior toggles: gmail_only_unseen controls whether only unread messages are scanned, and mark_read controls flag behavior.

Error Handling

  • Missing config keys raise KeyError with a list of missing entries.
  • IMAP selection or fetch failures raise RuntimeError, logged at the top level with stack traces.
  • Network errors from the fax API cause requests.HTTPError to be raised (after closing file handles), which is caught in main() and causes exit code 1.

Instrumentation

  • Uses Python's standard logging module configured at INFO level.
  • Logs both success (status code and body) and fatal errors (with stack trace) so calling systems can monitor behavior.
  • Temporary files are cleaned up automatically using tempfile.TemporaryDirectory.
