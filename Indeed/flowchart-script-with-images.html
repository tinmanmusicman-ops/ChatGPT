Flowchart with Images: Indeed Email-to-Sheet Processor

Each section includes a flow icon rendered as an inline SVG via a data URL.

[Start] → main()

  • Start by logging the run, loading config.json, and enabling Google API debug logging if requested.
  • Optionally clear the worksheet before the run when the earliest execution of the day needs a clean slate.
  • Choose between debug mode (process a saved body) or normal processing (loop over up to max_emails_per_run emails).

Debug vs Normal Loop

Debug branch

  • Read email_body.txt, optionally provided in debugging mode.
  • Run process_email_payload() with the saved content.
  • Finish immediately after logging completion.

Normal branch

  • Iterate while processed_count is below max_emails_per_run.
  • Fetch next unread job alert via get_unread_email_body().
  • If no message is found, exit the loop and log that zero emails were processed.
  • Otherwise, feed the message to process_email_payload() and increment the counter.

get_unread_email_body(cfg)

  • Connect to Gmail via secure IMAP, select the inbox, and search for unseen Primary-category emails.
  • Fetch the first match, prefer HTML parts, decode headers, and find forwarded original senders.
  • Call is_relevant_job_email() to ensure the body likely contains job alerts.

Relevance result

  • False: copy to NotRead, delete the original, logout, and return an empty tuple.
  • True: label as Processed, delete original, logout, and return the body tuple.

extract_jobs_from_email(...)

  • Start a timer, build an OpenAI client, and craft the prompt by concatenating the subject and body.
  • Call the Responses API with EXTRACTION_PROMPT and parse the first JSON chunk from the output.
  • Respect max_jobs_per_email from the configuration while normalizing each job’s fields.
  • Return the job list plus elapsed AI time for sheet annotations.

append_jobs_to_sheet(...)

  • Obtain the worksheet via get_gsheet_worksheet(), ensuring headers and formatting helpers are satisfied.
  • Load cached URLs to avoid duplicates and build row data with timestamp, elapsed time, job metadata, and raw SWOT.
  • Append rows via gspread and annotate every new cell with hover notes, including formatted SWOT details.

Helper branches

  • is_relevant_job_email() checks keywords/domains for job-related clues before any AI call.
  • extract_original_sender_from_body() finds forwarded “From:” lines when present.
  • get_gsheet_worksheet() authorizes the service account, opens the spreadsheet/workbook, and caches handles.
  • _format_swot_text() makes notes human-friendly when creating cell comments.

[End]

Logs final summary and exits once the processing loop finishes.
