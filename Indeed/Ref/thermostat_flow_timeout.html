Seam Thermostat Script Flow

Bootstrap
Read config (defaults include request_timeout_minutes, temp_adjust).
Load saved request_state; drop if expired.
?
Email Scan
IMAP Primary UNSEEN.
Match subjects starting with AC.
Extract studio + optional minutes (AC21 15).
Persist request window (expires_at, studio, zone).
?
Active Request?
Yes: keep request state; Type becomes “request (studio N, Xm)”.
No: Type = system.
If prior request expired: plan to revert to schedule.
Seam Auth
Use API key or OAuth token for headers.
Expiration Revert
If request just expired: set cooling to cool_threshold_f, fan auto.
?
Apply Request
If active: fetch reading, set cooling to (current - 2°F), fan on.
?
Fetch Telemetry
Call /v1/devices/get; extract temps, modes, equipment.
System Auto-Adjust
If no active request: apply temp_adjust, compare to thresholds.
Set cooling to threshold if over; fan on above fan_on_above_f; circulate below fan_circulate_below_f.
Output & Log
Print current/target/mode to stdout.
Append row to Google Sheet “Thermostats”: Timestamp, Type, Current Temp, Cooling Set Point, Climate Setting, Fan Setting, Equipment Status, Studio.
Type carries studio + hold minutes when request-driven.
