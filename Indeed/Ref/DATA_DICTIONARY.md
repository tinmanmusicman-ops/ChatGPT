# 🗂️ Project Shoreline — Data Dictionary
**Generated:** November 11, 2025 07:21 AM

## Purpose
Defines the schema used by the *Indeed → AI → Sheets* automation pipeline.  
Each row represents a fully processed job notification or event.

| **Column Name** | **Type** | **Description / Purpose** |
|-----------------|-----------|----------------------------|
| **Timestamp** | `datetime (string)` | The exact time the entry was created. Format: *Day, Month DD, YYYY at HH:MM:SS AM/PM*. Used for chronological tracking and audit purposes. |
| **Job Title** | `string` | The position or opportunity title parsed from the email body. Identifies the core subject of the entry. |
| **Company** | `string` | The employer or organization offering the position. Extracted by AI from the email or URL context. |
| **Location** | `string` | City, state, or remote designation of the opportunity. Helps categorize listings geographically. |
| **Primary URL** | `string` | The first or most relevant job link. Used for one-click verification or direct navigation. |
| **All URLs** | `string (semicolon-separated)` | List of all extracted URLs from the email body, including duplicates or alternate versions. Retained for traceability. |
| **AI Summary** | `string (multiline)` | The structured overview of the opportunity generated by OpenAI — typically benefits, pay structure, and qualifications. Presented as human-readable bullets. |
| **Confidence Score** | `float (0.0–1.0)` | AI’s internal confidence in the accuracy and structure of the extracted data. Values ≥ 0.8 are considered reliable. |
| **Email UID (optional)** | `int` | The IMAP unique identifier of the processed message. Used to prevent duplicate processing in scheduled polling runs. |
| **Source (optional)** | `string` | Indicates the origin of the entry (e.g., `Indeed`, `LinkedIn`, `SMS`, etc.) if this framework is repurposed. Enables multi-source scalability. |

---

### 🧭 Notes for Future Versions
- **Repurposable:** The same schema supports other message sources (security logs, service requests, event reports).  
- **Optional Enrichment Fields:** Add columns such as `Category`, `Urgency`, or `Action Taken` when expanding beyond Indeed data.  
- **Formatting Logic:** Header row is bold, frozen, and banded automatically; new entries append at the bottom with fresh timestamp.
