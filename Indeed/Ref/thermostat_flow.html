Thermostat Script Flow

How the script scans email, maps studios to zones, updates devices, and logs to Sheets.

Load Settings

Read config.json for Gmail, Seam, Sheet, and thresholds. Derive API endpoints and defaults.

Scan Primary Inbox (Unread)

IMAP UID SEARCH UNSEEN X-GM-RAW "category:primary". Fetch full messages and filter subjects starting with AC.

Route to Zone

Parse the studio number from ACNN. Map to zones (Z1: 4,6,8; Z2: 3,5,7,2,9,20,21; Z3: 10–13; Z4: 16–19) and select the thermostat id (defaults to base id).

Apply Request Actions

For matched requests: set cooling to 72°F and fan on via Seam API. AC emails are marked seen and moved to Thermostats folder.

Fetch Live Telemetry

Call /v1/devices/get to pull current temperature, climate, fan, and equipment status. System path also auto-adjusts based on thresholds.

Log to Google Sheet

Append to Thermostats tab: Timestamp, Type (system or request + studio), Current Temp, Cooling Set Point, Climate Setting, Fan Setting, Equipment Status, Studio.

Report to Console

Print email matches (if any), zone/studio mapping, and the final Seam thermostat reading.
