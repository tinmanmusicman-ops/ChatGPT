Indeed Processor Flow
A Vizio-inspired layout that pairs text depth with iconography for each step.

Start / main()

Configuration, debug gating, and loop control.

  • Load config.json and optionally enable Google API debug logs.
  • Clear sheet once if clear_sheet_before_run is true.
  • Choose debug mode (single file) else normal mode loop.

Debug / Normal Branch

Decide execution flow.

  • Debug: read email_body.txt, run process_email_payload() with context, and exit.
  • Normal: loop until max_emails_per_run; each iteration fetches an unseen email.

get_unread_email_body()

Fetches Gmail alerts and filters.

  • Connect IMAP SSL, search Primary unseen, fetch first match.
  • Prefer HTML payload; detect original sender from forwarded blocks.
  • Apply is_relevant_job_email(); non-job → copy to NotRead and delete.

extract_jobs_from_email()

Calls OpenAI and parses responses.

  • Build prompt (subject + body) and call Responses.create with EXTRACTION_PROMPT.
  • Parse JSON output, strip everything beyond the first object, and limit jobs to max_jobs_per_email.
  • Normalize fields (job_name, company_summary, location, salary, work_arrangement, SWOT, decision factors, URL).
AI elapsed time is returned to annotate the sheet and log the run.

append_jobs_to_sheet()

Writes jobs with metadata and notes.

  • Get worksheet via service account and cache the handle.
  • Ensure headers + wrapping; read cached URLs to skip duplicates.
  • Build rows with timestamp, elapsed seconds, hyperlink, company, location, salary, decisions, and raw SWOT.
  • Append rows with USER_ENTERED and add hover notes through update_note.

Helper utilities

Support functions and formatting.

  • is_relevant_job_email(): keyword/domain heuristics.
  • extract_original_sender_from_body(): regex for forwarded From lines.
  • _format_swot_text(): cleans up multi-line SWOT for notes.
  • get_gsheet_worksheet() caches credentials; _clear_data_rows_and_comments() cleans sheet when flagged.

Finish / Exit

Log totals and exit.

  • After the loop finishes, log how many emails were processed.
  • Terminate the script cleanly.
