## Charging the Battery
[tags: charging, battery, power]


### Using USB Cable
[tags: usb, cable, charging]

1. Plug USB cable into wall charger
2. Plug charger into wall outlet
3. Plug cable into phone

### Using Charging Dock
[tags: dock, charger, placement]

1. Plug USB cable into charger
2. Plug charger into wall
3. Plug cable into dock
4. Place phone on dock

**Note:** Red LED flashes when battery is low.

## Turning the Phone On (First Time)
[tags: power-on, setup, first-use]

1. Press and hold Power
2. Review Terms & Conditions
3. Select language
4. Choose menu layout (List or Large View)
5. Main Menu appears

## Setting Up Voicemail
[tags: voicemail, security, pin]

1. Select **Get Started**
2. Enter a 4–7 digit PIN
3. Save and finish

# Section 2: Learning the Basics
[tags: basics, everyday-use, tasks]


## Power On / Off
[tags: power, on-off, controls]

- Press and hold Power button

## Adding a Contact
[tags: contacts, add, directory]

1. Main Menu → Contacts
2. Add Contact
3. Enter first name, last name, phone number
4. Save

## Making a Call
[tags: calling, dial, phone]

- Dial number and press Call
- Or select contact → Dial

## Sending a Text Message
[tags: texting, messaging, sms]

1. Main Menu → Text Messages
2. Options → Compose New Text
3. Select recipient
4. Type message and send

## Taking a Photo
[tags: camera, photo, capture]

1. Main Menu → Take Photo
2. Aim camera
3. Press OK to capture

## Voicemail Greeting
[tags: voicemail, greeting, audio]

1. Phone → Voicemail → Options
2. Set Up Greeting
3. Record, play, save

## Connecting to Wi‑Fi
[tags: wifi, connectivity, networks]
1. Settings → Wi‑Fi & Networks
2. Select Wi‑Fi
3. Choose network
4. Enter password
