Seam Thermostat – Email ? Action Flow

Gmail AC request ? Apply override ? Log to Google Sheet ? Revert after timeout

1
Load Config
Read config.json: Seam API key, Gmail creds, Sheet ID, thresholds, timeout, time zone, test flag.
2
Restore State
Check request_state.json. If expired, clear it; otherwise, keep active request info.
3
Scan Gmail
Primary inbox, unseen. Pull subject+body. Clean body to plain text.
4
Parse Request
Find user text like “AC10 30”. Extract studio=10, timeout=30m, map to zone thermostat.
5
Save Window
Store request + expiration in request_state.json. Build Type label for Sheet.
6
Expired?
If a previous request just expired: plan to revert set point + fan to schedule.
7
Fetch Telemetry
Call Seam /devices/get. Read current temp, target, mode, fan, equipment status.
8
Apply Request
If active request: set cooling to current minus 2°F, turn fan on.
9
System Safety
If no request: temp_adjust then compare thresholds; set cooling, fan on, or circulate.
10
Revert
If request expired: reset set point to threshold, fan to auto.
11
Log & Output
Print reading. Append to Sheet: Timestamp, Type (studio, zone, minutes), temps, mode, fan, equipment, studio, expiration time.
12
Sheet Result
Row added to “Thermostats” tab with local timestamps (Pacific) and expiration time.
Icons denote step order. Lines indicate flow from left to right, top to bottom.
