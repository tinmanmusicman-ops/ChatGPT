Indeed Flowchart

Detailed Vizeo-style boxes supported by connectors to guide each decision branch.

Start / main()

Entry, configuration, and mode selection.

  • Load config.json; optional Google debug logging.
  • Clear sheet if clear_sheet_before_run flag is set.
  • Switch to debug mode when requested (single execution) or continue to normal loop.

Mode decision

Debug branch vs normal loop.

  • Debug: load email_body.txt, run process_email_payload() once.
  • Normal: loop while under max_emails_per_run and fetch each unread email.

get_unread_email_body()

IMAP access + filtering.

  • IMAP SSL login, select INBOX, search Primary unseen messages.
  • Fetch first email; prefer HTML part, detect forwarded sender.
  • Use is_relevant_job_email(); non-job emails are relabeled to NotRead and deleted.

extract_jobs_from_email()

AI extraction & normalization.

  • Build prompt from subject + body; call OpenAI Responses API with EXTRACTION_PROMPT.
  • Parse the returned JSON, clamp to max_jobs_per_email.
  • Extract job_name, company summary, work arrangement, salary, location, decision factors, SWOT, and URLs.

Elapsed time is captured for annotation.

append_jobs_to_sheet()

Sheet writes + notes.

  • Authorize via service account, open spreadsheet, cache worksheet handle.
  • Ensure headers, wrap/clipping, and load cached URLs to avoid duplicates.
  • Build rows with timestamp, elapsed seconds, hyperlinks, metadata, and raw SWOT.
  • Append rows with USER_ENTERED, update URL cache, and add notes via update_note().

Finish / Exit

Log totals and terminate.

  • After loop finishes, report how many emails were processed.
  • Exit cleanly.
