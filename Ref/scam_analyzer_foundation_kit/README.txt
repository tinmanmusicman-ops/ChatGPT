
# Scam Analyzer Project (Full Set)

This folder includes everything:
- scam_analyzer.py — main script
- config.example.json — copy to config.json and fill in credentials
- run_scam_analyzer.bat — one-click launcher
- install_scheduler.bat — registers Task Scheduler job (every 5 min)
- schedule_every_5min.xml — XML import version

Quick start:
1. Copy config.example.json -> config.json and fill in values.
2. Run run_scam_analyzer.bat to test manually.
3. Double-click install_scheduler.bat to automate every 5 minutes.
