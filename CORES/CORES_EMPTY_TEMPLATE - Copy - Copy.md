### PROJECT: Test

- Situation:
Conversion of legacy POSTNET barcode system to USPS Intelligent Mail Barcode (IMb) format to meet compliance requirements and enable full-service mail tracking. The project required USPS verification, certification, barcode alignment validation, and significant backend system modifications.

- What I did:
Led the implementation of IMb encoding to replace POSTNET across print and mail workflows. Managed USPS verification and certification processes, resolved alignment and readability issues, updated backend systems to support IMb data structures, implemented unique serial number logic, and modified data handling to support tracking and compliance requirements. Coordinated testing to ensure barcode accuracy, scanner readability, and production stability.

- Tools / systems:
USPS IMb specifications, barcode generation logic, backend mail processing systems, presort integration, print stream modifications, USPS testing and certification environments, tracking data storage systems.

- Result:
Successfully deployed IMb across production workflows with USPS certification approval. Achieved compliant barcode readability and enabled piece-level tracking and automation benefits. Stabilized backend processes to support ongoing IMb operations without disruption.

- Evidence / artifacts:
USPS certification confirmation, barcode test scan reports, backend change documentation, production deployment records, tracking data validation samples.

Project required coordination across technical, compliance, and operational teams. USPS testing environments introduced delays, and alignment tolerances required multiple validation cycles before approval.

### PROJECT:

- Situation:
A business process relied heavily on manual spreadsheet updates, including opening files, correcting ZIP codes, standardizing fields, and reorganizing data. These repetitive tasks were time-consuming and introduced significant risk of human error. Additionally, incoming spreadsheets lacked standardization, creating inconsistencies in formatting and structure that further complicated the workflow.

- What I did:
I led the effort to convert the manual workflow into an automated process using AI-driven scripting and batch processing. I analyzed the recurring tasks, identified patterns in the inconsistencies, and built scripts to automatically clean, standardize, and correct data (such as ZIP code formatting and field normalization). To address inconsistent spreadsheet structures, I customized prompts and logic to allow engineered intelligence to interpret and reconcile data variations. I also designed and implemented a clear folder hierarchy and established network access controls to centralize resources and improve collaboration.

- Tools / systems:
- AI-based data processing and prompt engineering
- Batch processing scripts
- Spreadsheet automation tools
- Shared network folders with structured hierarchy
- Access control configuration for resource sharing

- Result:
The manual process was successfully transformed into an automated, repeatable workflow. Processing time was significantly reduced, and the margin for human error decreased substantially. Despite initial challenges with inconsistent data formats, the solution proved stable, scalable, and easy to maintain. The centralized folder structure and network access improved organization and team efficiency.

- Evidence / artifacts:
- Automation scripts for spreadsheet cleaning and normalization
- Before-and-after process comparison documentation
- Standardized folder hierarchy structure
- Sample input/output files demonstrating automated corrections

- Notes / caveats:
Data inconsistency across source spreadsheets required ongoing prompt customization and logic refinement. While the system handled most variations effectively, edge cases occasionally required minor updates to maintain accuracy.
